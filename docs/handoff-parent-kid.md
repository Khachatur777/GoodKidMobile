# Handoff: GoodKid — Parent & Kid screens (React Native)

Источник: проект Claude Design «Good Kid App v2», файл `Good Kid Parent & Kid.dc.html`
(все экраны, светлая и тёмная тема, кадры 390×844, у каждого кадра `data-screen-label`).
Базовая система — `Good Kid App v2.dc.html`.

HTML — это референс. Экраны собираются компонентами приложения, разметка не портируется.

## Правила продукта, заложенные в макеты
- Две роли: PARENT и KID. Регистрируется только родитель.
- Вход родителя: почта и пароль либо Google / Apple. Вход ребёнка: логин и пароль, которые завёл родитель.
- Максимум 3 ребёнка на родителя.
- PIN-экранов нет. Взрослые разделы закрыты арифметическим parental gate.
- Фильтр принадлежит ребёнку и настраивается родителем. В детском интерфейсе управления фильтром нет.
- Аватары детей — только пресеты (12 персонажей). Загрузки фото нет.
- Подписки выключены: пейволов и премиум-значков нет.
- Детская категория сторов: ни рекламы, ни чужих логотипов, ничего похожего на ссылку наружу в детском UI.
  Кнопки Google/Apple живут только на родительском входе.

## Поведение
- Онбординг показывается один раз (флаг сохраняется); Skip и «I already have an account» ведут на Sign in.
- Переключатель роли сохраняет введённые значения для каждой роли отдельно.
- Parental gate: новый вопрос при каждом открытии, попытки не ограничены, закрытие возвращает на предыдущий экран;
  пройденный гейт открывает раздел Children и действует до конца сессии.
- Фильтр: категории мультивыбором, возраст и язык — по одному; Save пишет только выбранному ребёнку;
  переключение ребёнка с несохранёнными изменениями спрашивает про сброс.
- Список детей: Edit → экран 9, Activity → экран 11, нажатие на карточку → Edit. На трёх детях Add выключен.
- Add child: проверка по сабмиту; занятый логин возвращает фокус в поле логина с видимой ошибкой.
- Удаление ребёнка разлогинивает его на всех устройствах.
- Активность: диапазон приходит с сервера, шапка рисует то, что вернулось.
- Детская сессия: выйти к родительским настройкам можно только через logout.
- Переходы: шторки выезжают 240ms ease-out с затемнением; диалоги 0.96 → 1 за 180ms; нажатие 0.97 за 120ms.
